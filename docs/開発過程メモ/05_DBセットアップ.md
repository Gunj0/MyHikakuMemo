# DB セットアップ

## NuGet 追加

- [Npgsql.EntityFrameworkCore.PostgreSQL](https://www.nuget.org/packages/Npgsql.EntityFrameworkCore.PostgreSQL)
  - PostgreSQL 用のデータベースプロバイダ
- [Microsoft.EntityFrameworkCore.Design](https://www.nuget.org/packages/microsoft.entityframeworkcore.design/)
  - dotnet ef migrations の実行に必要

## Data/Entities/{EntityName} クラス 作成

```cs
public class {EntityName}
{
    [Key]
    public int {PropertyName} { get; set; } = "";
}
```

## Data/ApplicationDbContext 作成

```cs:AppDbContext.cs
public class ApplicationDbContext(DbContextOptions options)
    : DbContext(options)
{
    DbSet<{EntityName}> {EntityNames} => Set<{EntityName}>();
    // DbSet<{EntityName}> {EntityNames} { get; set; } よりも再代入不可なSetが推奨
}
```

## Program.cs へ DbContext の追加

```cs
builder.Services.AddDbContext<ApplicationDbContext>(options =>
    options.UseNpgsql(
        builder.Configuration.GetConnectionString("DefaultConnection")
        ?? throw new InvalidOperationException("接続文字列が設定されていません"))
);
```

## appsettings.Development.json に接続文字列追加

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database={DbName};User Id=user;Password=password;"
  }
}
```

## docker-compose.yaml に DB コンテナ追加

```yaml
services:
  { service-name }:
    (略)
    environment:
      ASPNETCORE_ENVIRONMENT: Development
      ConnectionStrings__DefaultConnection: Host=db;Port=5432;Database={DbName};Username=user;Password=password
    depends_on:
      - db # dbサービスが起動してから起動するように設定
  db:
    # postgres https://hub.docker.com/_/postgres
    image: postgres:17 # Neonのバージョンに合わせる
    restart: always
    container_name: postgres
    ports:
      - 5432:5432
    volumes:
      # ボリュームをマウント(外部Volume(db-store) : コンテナ内ディレクトリ)
      - db-store:/var/lib/postgresql/data
    environment:
      POSTGRES_DB: {DbName} # 初期接続データベース名
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password
volumes:
  db-store: # db_storeという名前でボリュームを作成
```

## docker-compose 起動

```zsh
docker compose up -d
# -d: バックエンド実行
```

## DB マイグレーション

```zsh
% dotnet ef migrations add Initialize
% dotnet ef database update
```

Migrations ディレクトリは Data ディレクトリ下に移動しておく
