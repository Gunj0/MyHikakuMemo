# 初期セットアップ

## ソリューションファイル作成

```zsh
% dotnet new sln -n {SolutionName}
テンプレート "ソリューション ファイル" が正常に作成されました。
```

## WebAPI プロジェクト作成

```zsh
% dotnet new webapi -o {ProjectName}
テンプレート "ASP.NET Core Web API" が正常に作成されました。

作成後の操作を処理しています...
{ProjectName}.csproj を復元しています:
正常に復元されました。
```

## プロジェクトをソリューションに追加

```zsh
% dotnet sln add {ProjectName}
プロジェクト `{ProjectName}.csproj` をソリューションに追加しました。
```

## Git 初期化

```zsh
% git init
Initialized empty Git repository in .git/
```

## gitignore 追加

```zsh
% dotnet new gitignore
テンプレート "dotnet gitignore ファイル" が正常に作成されました。
```

## ビルド

```zsh
% dotnet build
復元が完了しました (0.3 秒)
  {ProjectName} 成功しました (1.5 秒) → {ProjectName}.dll

2.1 秒後に 成功しました をビルド
```
